# Awesome Free and Open-Source Software [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> High-quality software that costs nothing to use and publishes source code under a license permitting inspection, modification, and redistribution.

Part of [Awesome Abundance](../README.md) and [akashic](../../../README.md), the Ego Hygiene knowledge collection.

Free and open-source software is about user freedom as well as price. Hosted services, proprietary plugins, support, storage, or convenient prebuilt packages may still have optional costs even when the listed software itself is free and open source.

## Discovery and Distribution

- [F-Droid](https://f-droid.org/) - Free and open-source Android app repository whose clients and catalog emphasize auditable builds and clearly disclosed anti-features.
- [Flathub](https://flathub.org/) - Community storefront for installing Linux desktop applications packaged as Flatpaks, with source and verification status exposed per app.
- [Homebrew](https://brew.sh/) - Open-source package manager providing no-cost command-line software installation on macOS and Linux.
- [Chocolatey Community](https://community.chocolatey.org/packages) - Public package repository used by the open-source Chocolatey client to automate Windows software installation, with some commercial features optional.
- [Scoop](https://scoop.sh/) - Open-source command-line installer for Windows that keeps applications isolated in user directories and supports community buckets.
- [OpenAlternative](https://openalternative.co/) - Community directory for finding open-source alternatives to proprietary software and hosted products.
- [Open Source Alternative](https://www.opensourcealternative.to/) - Searchable catalog matching commercial products with free and open-source alternatives by use case.
- [Awesome Selfhosted](https://awesome-selfhosted.net/) - Community-maintained catalog of free software network services and web applications that can be hosted independently.
- [PRISM Break](https://prism-break.org/) - Curated directory of free and open-source alternatives intended to reduce reliance on proprietary surveillance platforms.
- [switching.software](https://switching.software/) - Practical directory of ethical, privacy-conscious, and open alternatives to widely used online services and applications.
- [Awesome Curated Lists](https://awesome.re/) - Entry point to the Awesome ecosystem of community-curated lists, including many catalogs of free and open-source software.
- [AlternativeTo](https://alternativeto.net/) - Crowdsourced software-recommendation site with license filters for finding free and open-source replacements for specific applications.
- [Free Programming Books](https://github.com/EbookFoundation/free-programming-books) - Multilingual community list of freely available programming books, courses, cheat sheets, and interactive tutorials.
- [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets) - Community-maintained index of openly available datasets grouped by discipline and linked to their original sources.
- [Awesome Free Software](https://github.com/johnjago/awesome-free-software) - Curated list of software that respects user freedom, organized by category with license information.

## Operating Systems

- [Debian](https://www.debian.org/) - Community-governed GNU/Linux distribution composed primarily of free software and available without license fees.
- [Fedora Workstation](https://fedoraproject.org/workstation/) - Community Linux desktop sponsored by Red Hat and built from free and open-source software.
- [Ubuntu Desktop](https://ubuntu.com/desktop) - No-cost Linux desktop distribution with open-source foundations, long-term-support releases, and optional commercial services.
- [Linux Mint](https://linuxmint.com/) - Community-funded Linux desktop focused on familiar workflows, multimedia support, and ease of installation.
- [Pop!_OS](https://pop.system76.com/) - Free Linux desktop from System76 with open-source workflow, graphics, and recovery tooling.
- [Qubes OS](https://www.qubes-os.org/) - Security-focused desktop operating system that isolates activities into disposable and persistent virtual machines.
- [FreeBSD](https://www.freebsd.org/) - Free and open-source Unix-like operating system for servers, desktops, networking, storage, and embedded systems.
- [OpenBSD](https://www.openbsd.org/) - Free Unix-like operating system emphasizing correctness, proactive security, cryptography, and integrated documentation.
- [Raspberry Pi OS](https://www.raspberrypi.com/software/) - Debian-based operating system provided free for Raspberry Pi computers, with desktop and minimal editions.
- [GNU Project](https://www.gnu.org/) - Home of the free software operating system and utilities that established copyleft licensing, with source available for every component.

## Office, Notes, and Everyday Work

- [LibreOffice](https://www.libreoffice.org/) - Full open-source office suite for documents, spreadsheets, presentations, drawings, databases, and formulas.
- [ONLYOFFICE Desktop Editors](https://www.onlyoffice.com/desktop.aspx) - Free open-source desktop suite for documents, spreadsheets, presentations, forms, and PDF files.
- [Joplin](https://joplinapp.org/) - Open-source notes and to-do application with Markdown, end-to-end encryption, attachments, plugins, and user-chosen synchronization.
- [Logseq](https://logseq.com/) - Local-first open-source outliner for linked notes, journals, tasks, whiteboards, and knowledge graphs.
- [Zettlr](https://www.zettlr.com/) - Open-source Markdown editor designed for academic writing, notes, citations, and long-form projects.
- [calibre](https://calibre-ebook.com/) - Open-source ebook library manager supporting conversion, metadata, device transfer, editing, reading, and content servers.
- [Okular](https://okular.kde.org/) - KDE universal document viewer for PDF, EPUB, comics, images, DjVu, annotations, signatures, and accessibility features.
- [Sumatra PDF](https://www.sumatrapdfreader.org/free-pdf-reader) - Lightweight open-source Windows reader for PDF, EPUB, MOBI, comics, DjVu, XPS, and image files.
- [PDF Arranger](https://github.com/pdfarranger/pdfarranger) - Cross-platform open-source graphical tool for merging, splitting, rotating, cropping, and rearranging PDF pages.
- [Stirling PDF](https://www.stirlingpdf.com/) - Open-source, locally runnable suite of browser-based PDF conversion, editing, OCR, signing, and security tools.
- [diagrams.net](https://www.diagrams.net/) - Free open-source diagram editor that works in a browser or desktop application and can store files locally.
- [KDE Connect](https://kdeconnect.kde.org/) - Open-source integration for sharing files, notifications, clipboard data, input, and commands between computers and mobile devices.
- [LocalSend](https://localsend.org/) - Free cross-platform file and message transfer over a local network without accounts, cloud storage, or internet access.
- [Syncthing](https://syncthing.net/) - Open-source peer-to-peer file synchronization that keeps data on user-controlled devices instead of a central cloud.

## Creative Work

- [Blender](https://www.blender.org/) - Professional open-source suite for 3D modeling, sculpting, animation, rendering, compositing, video editing, and visual effects.
- [GIMP](https://www.gimp.org/) - Open-source raster image editor with layers, color tools, selection, retouching, automation, and extensible file-format support.
- [Krita](https://krita.org/) - Free professional painting and illustration application with brush engines, animation, color management, and drawing assistants.
- [Audacity](https://www.audacityteam.org/) - Cross-platform open-source multitrack audio recorder and editor with effects, plugins, analysis, and format conversion.
- [LMMS](https://lmms.io/) - Free digital audio workstation for sequencing, synthesis, sampling, MIDI, effects, and music production.
- [MuseScore Studio](https://musescore.org/) - Open-source music notation editor for composing, arranging, engraving, playback, MIDI, and printable scores.
- [OBS Studio](https://obsproject.com/) - Open-source software for live streaming, screen recording, scene composition, audio mixing, and hardware capture.
- [Kdenlive](https://kdenlive.org/) - KDE nonlinear video editor with multitrack timelines, proxy workflows, effects, scopes, subtitles, and broad codec support.
- [Shotcut](https://shotcut.org/) - Cross-platform open-source video editor with native timeline editing, filters, capture, hardware acceleration, and extensive format support.
- [OpenShot](https://www.openshot.org/) - Accessible open-source nonlinear video editor with tracks, transitions, keyframes, titles, effects, and cross-platform builds.
- [HandBrake](https://handbrake.fr/) - Open-source video transcoder for converting common media formats with presets, filters, subtitles, and hardware encoders.
- [darktable](https://www.darktable.org/) - Open-source photography workflow and raw developer providing nondestructive editing, color management, tethering, and asset organization.
- [RawTherapee](https://rawtherapee.com/) - Cross-platform raw-photo processor with advanced demosaicing, color, exposure, detail, lens, and batch-processing tools.
- [Scribus](https://www.scribus.net/) - Open-source desktop-publishing application for print layouts, typography, color management, forms, and press-ready PDF output.
- [Natron](https://natrongithub.github.io/) - Node-based open-source compositor for visual effects, keying, tracking, rotoscoping, and image-processing pipelines.
- [Godot Engine](https://godotengine.org/) - Community-driven open-source game engine for 2D and 3D projects with an integrated editor, scripting, animation, and export tools.
- [FreeCAD](https://www.freecad.org/) - Open-source parametric 3D modeler for mechanical design, architecture, engineering, fabrication, and extensible CAD workflows.
- [KiCad](https://www.kicad.org/) - Open-source electronics-design suite for schematics, printed circuit boards, simulation, manufacturing files, and 3D inspection.

## Internet, Communication, and Media

- [Firefox](https://www.mozilla.org/firefox/) - Open-source web browser from Mozilla with cross-platform synchronization, extensions, tracking protection, and developer tools.
- [Signal](https://signal.org/) - Free open-source messaging and calling application with end-to-end encryption by default and nonprofit stewardship.
- [Element](https://element.io/) - Open-source Matrix client for decentralized messaging, rooms, encrypted calls, and self-hosted or public homeservers.
- [Jitsi Meet](https://jitsi.org/jitsi-meet/) - Open-source video-conferencing software available through public instances or independent self-hosting.
- [SimpleX Chat](https://simplex.chat/) - Open-source private messenger using decentralized relays without requiring phone numbers, email addresses, or persistent user identifiers.
- [Briar](https://briarproject.org/) - Peer-to-peer encrypted messenger that can synchronize through Tor, Wi-Fi, or Bluetooth and is designed for resilient communication.
- [VLC](https://www.videolan.org/vlc/) - Cross-platform open-source media player supporting a vast range of audio, video, streaming, subtitle, and disc formats.
- [mpv](https://mpv.io/) - Scriptable open-source media player with high-quality video output, broad codec support, command-line control, and embeddable libraries.
- [qBittorrent](https://www.qbittorrent.org/) - Open-source BitTorrent client with search, RSS, remote control, sequential downloads, and no bundled advertising.
- [Transmission](https://transmissionbt.com/) - Lightweight open-source BitTorrent client with native desktop interfaces, daemon operation, remote control, and minimal resource use.
- [AntennaPod](https://antennapod.org/) - Free Android podcast manager with subscriptions, queues, playback controls, downloads, synchronization options, and no advertising.
- [Feeder](https://github.com/spacecowboy/Feeder) - Open-source Android feed reader with offline reading, notifications, filters, and no account requirement.
- [NewPipe](https://newpipe.net/) - Lightweight open-source Android media client that accesses supported platforms without proprietary Google services or an account.
- [Organic Maps](https://organicmaps.app/) - Privacy-focused open-source offline maps and navigation using OpenStreetMap data without tracking or advertising.
- [OsmAnd](https://osmand.net/) - Open-source offline maps and navigation with downloadable OpenStreetMap data; the F-Droid build provides the community edition.
- [Termux](https://termux.dev/) - Open-source Android terminal environment and package ecosystem that runs Linux command-line tools without rooting the device.
- [Thunderbird](https://www.thunderbird.net/) - Free open-source desktop client for email, calendars, contacts, chat, and feeds, maintained by the Thunderbird project at MZLA.
- [Kodi](https://kodi.tv/) - Open-source media center for organizing and playing local and networked video, music, photos, and add-on content across platforms.

## Privacy and Security

- [KeePassXC](https://keepassxc.org/) - Offline open-source password manager using encrypted local databases compatible with the KeePass format.
- [VeraCrypt](https://www.veracrypt.fr/) - Open-source disk-encryption software for encrypted containers, partitions, drives, and pre-boot system protection.
- [Cryptomator](https://cryptomator.org/) - Open-source client-side encryption for files stored with cloud providers, using transparent virtual drives and documented formats.
- [Aegis Authenticator](https://getaegis.app/) - Free open-source Android authenticator with encrypted backups, import and export, biometric unlock, and no account requirement.
- [Ente Auth](https://ente.io/auth/) - Open-source authenticator with optional end-to-end encrypted cross-device synchronization and free core access.
- [ClamAV](https://www.clamav.net/) - Open-source antivirus toolkit for malware scanning, signatures, email gateways, command-line automation, and server integration.
- [Wireshark](https://www.wireshark.org/) - Open-source network protocol analyzer for live capture, packet inspection, troubleshooting, education, and security research.
- [OpenSnitch](https://github.com/evilsocket/opensnitch) - GNU/Linux application firewall that prompts for outbound connection decisions and records network activity.
- [Portmaster](https://safing.io/) - Open-source application firewall and privacy monitor with free local filtering features and optional paid network services.

## Accessibility

- [NVDA](https://www.nvaccess.org/download/) - Free open-source Windows screen reader with speech, braille-display support, extensible add-ons, and broad application accessibility.
- [Orca](https://help.gnome.org/users/orca/stable/) - Open-source screen reader for the Linux desktop supporting speech, braille, magnification workflows, and accessible applications.
- [BRLTTY](https://brltty.app/) - Background service providing refreshable braille-display access to Linux and other text consoles across many hardware models.
- [Speech Dispatcher](https://freebsoft.org/speechd) - Open-source speech-synthesis interface used by assistive technologies to coordinate voices, priorities, and output across applications.

## Development and Data

- [VSCodium](https://vscodium.com/) - Community builds of the open-source Visual Studio Code codebase without Microsoft's proprietary branding and telemetry defaults.
- [Neovim](https://neovim.io/) - Extensible open-source text editor built for modal editing, scripting, language tooling, remote interfaces, and modern plugins.
- [GNU Emacs](https://www.gnu.org/software/emacs/) - Long-lived extensible free software editor and computing environment for text, code, email, knowledge management, and automation.
- [Helix](https://helix-editor.com/) - Modal open-source code editor with multiple selections, tree-sitter parsing, language-server support, and built-in defaults.
- [Eclipse IDE](https://www.eclipse.org/ide/) - Open-source extensible development environment with mature tooling for Java and a broad plugin ecosystem.
- [Apache NetBeans](https://netbeans.apache.org/) - Apache-licensed development environment for Java, PHP, JavaScript, HTML, and other languages.
- [IntelliJ IDEA Community Edition](https://www.jetbrains.com/idea/download/) - Free open-source edition of JetBrains' JVM development environment for Java and Kotlin projects.
- [Git](https://git-scm.com/) - Distributed open-source version-control system used for local history, collaboration, branching, merging, and automation.
- [Podman](https://podman.io/) - Daemonless open-source container engine and toolset compatible with OCI images, pods, rootless operation, and Docker-style workflows.
- [DBeaver Community](https://dbeaver.io/) - Free open-source universal database client supporting SQL editing, metadata browsing, data transfer, diagrams, and many database drivers.
- [PostgreSQL](https://www.postgresql.org/) - Advanced open-source relational database with transactional integrity, extensibility, indexing, JSON, geospatial extensions, and a global community.
- [MariaDB Community Server](https://mariadb.org/) - Community-developed open-source relational database compatible with much of the MySQL ecosystem.
- [SQLite](https://www.sqlite.org/) - Public-domain embedded SQL database engine distributed as a small library and included throughout operating systems and applications.
- [RStudio Desktop](https://posit.co/download/rstudio-desktop/) - Open-source integrated development environment for R and Python with free desktop builds from Posit.

## Science, Engineering, and Education

- [GNU Octave](https://octave.org/) - Free numerical computing language and environment largely compatible with MATLAB syntax for linear algebra, simulation, and visualization.
- [SageMath](https://www.sagemath.org/) - Open-source mathematics system combining algebra, calculus, number theory, numerical computation, and many specialist libraries.
- [Scilab](https://www.scilab.org/) - Free open-source numerical computation platform for modeling, simulation, optimization, signal processing, and control systems.
- [ImageJ](https://imagej.net/ij/) - Public-domain scientific image-processing application with measurement, analysis, automation, and a large plugin ecosystem.
- [Fiji](https://fiji.sc/) - Batteries-included distribution of ImageJ for scientific image analysis with curated plugins, scripting, and reproducible update sites.
- [Avogadro](https://avogadro.cc/) - Open-source molecular editor and visualization application for chemistry, materials science, education, and computational workflows.
- [Stellarium](https://stellarium.org/) - Open-source planetarium that renders a realistic, searchable sky from desktop, mobile, and browser applications.
- [Celestia](https://celestiaproject.space/) - Open-source real-time 3D astronomy simulation for exploring planets, stars, galaxies, spacecraft, and custom scientific data.
- [Anki](https://apps.ankiweb.net/) - Open-source spaced-repetition flashcard application with free desktop and web synchronization; the official iOS client is paid.
- [Moodle](https://moodle.org/) - Open-source learning-management platform for courses, assignments, assessment, communication, plugins, and institutional self-hosting.
- [GCompris](https://gcompris.net/) - Open-source educational suite of activities for children covering literacy, mathematics, science, geography, computers, and games.
- [OpenBoard](https://openboard.ch/) - Free open-source interactive whiteboard for schools and universities that works with projectors, displays, or standard computers.

## System Utilities and Backup

- [7-Zip](https://www.7-zip.org/) - Open-source Windows file archiver with high-compression 7z support and broad archive extraction capabilities.
- [PeaZip](https://peazip.github.io/) - Cross-platform open-source archive manager supporting creation, conversion, encryption, splitting, and extraction across many formats.
- [Flameshot](https://flameshot.org/) - Cross-platform open-source screenshot tool with capture selection, annotations, copying, saving, and configurable shortcuts.
- [ShareX](https://getsharex.com/) - Open-source Windows screen-capture, recording, OCR, automation, and upload workflow tool.
- [Rufus](https://rufus.ie/) - Open-source Windows utility for formatting and creating bootable USB drives from operating-system images.
- [Ventoy](https://www.ventoy.net/) - Open-source tool that boots multiple ISO, WIM, IMG, VHD, and EFI files directly from one USB device.
- [balenaEtcher](https://etcher.balena.io/) - Open-source cross-platform graphical application for writing operating-system images safely to removable drives.
- [GParted](https://gparted.org/) - Open-source graphical partition editor for creating, resizing, moving, checking, labeling, and copying disk partitions.
- [Clonezilla](https://clonezilla.org/) - Free disk-imaging and cloning system for individual machines, bare-metal recovery, and multicast deployment.
- [Rescuezilla](https://rescuezilla.com/) - Open-source graphical rescue environment for disk imaging, restoration, cloning, file access, and compatibility with Clonezilla images.
- [FileZilla Client](https://filezilla-project.org/) - Open-source graphical client for FTP, FTPS, and SFTP file transfers across Windows, macOS, and Linux.
- [WinSCP](https://winscp.net/) - Open-source Windows client for SFTP, FTP, WebDAV, S3, secure copying, synchronization, scripting, and remote file management.
- [restic](https://restic.net/) - Fast open-source backup program with encryption, deduplication, snapshots, verification, and support for many local and cloud backends.
- [BorgBackup](https://www.borgbackup.org/) - Deduplicating open-source backup tool with authenticated encryption, compression, remote repositories, mounts, and pruning.
- [rclone](https://rclone.org/) - Open-source command-line tool for copying, synchronizing, mounting, encrypting, and serving data across many storage providers.
- [Duplicati](https://duplicati.com/) - Open-source encrypted backup client with deduplication, scheduling, retention, a web interface, and local or remote destinations.
