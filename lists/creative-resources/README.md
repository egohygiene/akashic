## 3D Assets and Materials

- [3Dassets.one](https://3dassets.one/) - Search engine for finding 3D assets across multiple libraries with filters for license, source, tags, and asset type.
- [ambientCG](https://ambientcg.com/) - Library of freely downloadable CC0 materials, textures, HDRIs, models, and terrain assets for 3D workflows.
- [FreePBR](https://freepbr.com/) - Collection of free physically based rendering materials and texture maps for 3D art and game-development workflows.
- [img2threejs](https://github.com/img2threejs/img2threejs) - Tool for rebuilding objects from reference images as procedural, animation-ready, quality-gated Three.js models.
- [img2threejs Showcase](https://github.com/img2threejs/img2threejs-showcase) - Live gallery of procedural, code-only Three.js models generated from reference images by img2threejs.
- [Sketchfab Free 3D Models](https://sketchfab.com/tags/free) - Tag-based catalog of free downloadable 3D models on Sketchfab; individual asset licenses and attribution terms vary.
- [Spline](https://app.spline.design/home) - Account-based collaborative editor for designing, animating, and publishing interactive three-dimensional scenes; export and collaboration features vary by plan.
- [TurboSquid](https://www.turbosquid.com/) - Commercial 3D-model marketplace that also includes free models; licensing and usage terms vary by asset.

## Audio and Music

- [AbleSet](https://ableset.com/) - Commercial set-list and performance-control application for Ableton Live that coordinates songs, markers, lyrics, cues, and remote controls across devices.
- [Matchering](https://github.com/sergree/matchering) - Open-source audio matching and mastering library for shaping a target track from the tonal and dynamic profile of a reference.
- [Voicebox](https://voicebox.sh/) - Open-source desktop application for local voice cloning, speech generation, model management, and audio workflows.
- [WhatBPM](https://github.com/sergree/whatbpm) - Open-source EDM tempo, key, label, genre, and track-length analytics project; its published dataset may be stale.

## Image, Video, and Visualization

- [Bento4](https://www.bento4.com/) - Cross-platform C++ SDK and command-line toolkit for reading, writing, inspecting, encrypting, and packaging MP4, DASH, HLS, and CMAF media.
- [Chicago Film Archives](https://www.chicagofilmarchives.org/) - Preserves more than 40,000 Midwest films and related media, with searchable collections and thousands of items streamable online.
- [Faceswap](https://github.com/deepfakes/faceswap) - Open-source deep-learning application for training and producing face-swap media across supported hardware backends.
- [Flourish](https://flourish.studio/) - No-code platform for building interactive data visualizations, maps, stories, presentations, and embeddable graphics.
- [Freeze](https://github.com/charmbracelet/freeze) - Command-line tool for rendering code, terminal output, and interactive terminal sessions as polished images.
- [Gemini Video Watermark Remover](https://geminiwatermarkremover.io/video) - Browser-based service for removing visible Gemini and Veo watermarks from uploaded videos.
- [Gemini Watermark Remover](https://github.com/GargantuaX/gemini-watermark-remover) - Client-side JavaScript tool for removing Gemini image and video watermarks through reverse alpha blending.
- [image_optim](https://github.com/toy/image_optim) - Ruby library and command-line interface that coordinates multiple utilities to compress JPEG, PNG, GIF, and SVG assets.
- [Imagineer](https://github.com/foresterre/imagineer) - Rust command-line frontend for image-rs that converts, batch-processes, and transforms static and animated images.
- [Kress Collection Digital Archive](https://kress.nga.gov/) - Explores the Samuel H. Kress Collection through digitized artworks, archival records, provenance, and institutional histories.
- [Leonardo AI](https://leonardo.ai/) - Generative creative platform for producing and editing images, illustrations, design assets, and video.
- [Limecraft](https://www.limecraft.com/) - Commercial video-production workspace for ingest, transcription, metadata, review, collaboration, subtitling, and delivery across media teams.
- [Manim](https://github.com/3b1b/manim) - Animation engine created by 3Blue1Brown for programmatically producing precise mathematical explanations and visualizations.
- [OpenMontage](https://www.openmontage.video/) - Open-source agentic video-production workspace for research, scripting, asset collection, editing, and repeatable media pipelines.
- [Palmier Pro](https://www.palmier.io/) - Commercial video editor designed around AI-assisted composition, generative media, timelines, and collaborative production.
- [Rive](https://rive.app/) - Design and runtime platform for building stateful vector animations and interactive graphics that can ship across web, application, game, and embedded interfaces.
- [Samek Art Museum Collection](https://collection.museum.bucknell.edu/) - Searches and browses digitized objects, exhibitions, and collection groups from Bucknell University's Samek Art Museum.
- [SD.Next](https://vladmandic.github.io/sdnext/) - Open-source local web interface for generating and editing images and video with Stable Diffusion and other supported models; installation requires compatible hardware and separately obtained model files.
- [Shutter Encoder](https://github.com/paulpacifico/shutter-encoder) - Cross-platform media conversion and processing application built around FFmpeg with editing, analysis, and delivery workflows.
- [soup.video](https://soup.video/) - Account-based AI video service for generating short-form clips from prompts and supported media; model access, quotas, output rights, and pricing depend on the service terms.
- [SVGO](https://github.com/svg/svgo) - Node.js library and command-line optimizer that applies configurable transformations to SVG files.
- [Upscayl NCNN](https://github.com/upscayl/upscayl-ncnn) - Upscayl's NCNN and Real-ESRGAN-powered backend for GPU-accelerated image upscaling.
- [video-cli](https://github.com/wkentaro/video-cli) - Collection of command-line tools for quick video trimming, cropping, concatenation, conversion, and inspection.


## Media Processing, Provenance, and Watermarks

Use provenance and watermark tools only on media you own or are authorized to test. Removing origin or authenticity signals can violate law, contracts, platform rules, or the rights of creators and subjects.

- [C2PA Community Wiki](https://c2pa.wiki/) - Community reference for the Coalition for Content Provenance and Authenticity standard, ecosystem, concepts, and implementations.
- [C2PA Tool](https://github.com/contentauth/c2pa-rs/tree/main/cli) - Official command-line tool for reading, validating, creating, and signing C2PA manifests in supported media files.
- [Content Authenticity Initiative](https://contentauthenticity.org/) - Cross-industry initiative developing open standards and tools for verifiable digital-media provenance and Content Credentials.
- [Content Credentials Verify](https://verify.contentauthenticity.org/) - Browser-based verifier for inspecting Content Credentials and provenance attached to compatible media.
- [Credentio](https://mediaprovenance.googlesource.com/credentio/) - Google's open-source C++ library for locally parsing and validating C2PA Content Credentials across supported media formats.
- [DeSynth](https://github.com/0xROOTPLS/DeSynth) - Research-oriented utility for testing the robustness and detectability of SynthID-style image watermarks; use only on authorized media.
- [ExifTool](https://exiftool.org/) - Mature cross-platform command-line library and application for reading, writing, and editing metadata across many file formats.
- [FFmpeg](https://ffmpeg.org/) - Foundational open-source suite of libraries and command-line tools for recording, converting, filtering, streaming, and inspecting multimedia.
- [Gemini Watermark and SynthID Remover](https://github.com/froggeric/gemini-watermark-and-synthid-remover) - Cross-platform analysis tool for testing visible and invisible watermark removal from authorized Gemini, Veo, and NotebookLM media.
- [GPAC](https://gpac.io/) - Open-source multimedia framework for packaging, streaming, playing, inspecting, and transforming media across broadcast and web formats.
- [Invisible Watermark](https://github.com/ShieldMnt/invisible-watermark) - Python library for embedding and decoding robust invisible image watermarks for authorized provenance and robustness experiments.
- [MediaInfo](https://mediaarea.net/en/MediaInfo) - Displays technical and tag metadata for audio and video files through graphical, command-line, library, and web interfaces.
- [Remove AI Watermarks](https://github.com/wiltodelta/remove-ai-watermarks) - Python library and CLI for authorized analysis of visible marks, SynthID, C2PA, EXIF, IPTC, and XMP in images and video.
- [SynthID Bypass](https://github.com/cebeuq/Synthid-Bypass) - Experimental project for evaluating the robustness of SynthID image watermarks under transformations; use only on content you may lawfully modify.
- [SynthID](https://deepmind.google/models/synthid/) - Google DeepMind's system for embedding and detecting imperceptible watermarks in AI-generated images, audio, text, and video.
- [Text Stealth Watermark Cleaner and Detector](https://github.com/cronos3k/Text-Stealth-Watermark-Cleaner-Detector) - Browser tool that detects and removes hidden Unicode characters from text for authorized analysis and clean document transfer.
- [WatermarkRemover-AI](https://github.com/D-Ogi/WatermarkRemover-AI) - Open-source image inpainting utility for removing visible marks from content the user owns or is authorized to edit.

Suggestions and improvements are welcome. See the [contribution guidelines](../../contributing.md).
