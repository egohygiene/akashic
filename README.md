# Awesome [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated tree of awesome lists for tools, resources, knowledge, inspiration, and the open web.

This repository is the root index for the Ego Hygiene awesome collection. It begins intentionally small: categories will emerge from real resources instead of being imposed before the collection has enough material.

## Contents

- [Collections](#collections)
- [Meta](#meta)

## Collections

The collection is taking shape. New categories will be introduced as related resources accumulate, and larger branches can graduate into focused lists when that makes them easier to explore and maintain.

## Meta

- [Awesome](https://github.com/sindresorhus/awesome#readme) - The original index of curated awesome lists.

- [Awesome Manifesto](https://github.com/sindresorhus/awesome/blob/main/awesome.md) - Principles for thoughtful and useful curation.
