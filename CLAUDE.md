# Claude Repository Guide

@AGENTS.md

`AGENTS.md` is the canonical instruction set for this repository. Read and follow it before planning, editing, validating, or publishing changes. If the import syntax above is unavailable in the current Claude environment, open `AGENTS.md` directly.

Claude-specific expectations:

- Begin by inspecting the relevant canonical Markdown, scripts, site source, and current working-tree state.
- Keep a single source of truth: do not copy the full agent contract into this file or create Claude-only repository conventions.
- Use the validation matrix and definition of done from `AGENTS.md`, selecting every check relevant to the files changed.
- Surface uncertain curation judgments, skipped submissions, safety concerns, and migration decisions in the pull request rather than silently guessing.
- Preserve user work and ask before expanding scope when a requested change conflicts with existing repository policy.
